# Adidas
Adidas sales dashboard with charts and pivot table
Adidas Sales & Performance Analysis – Microsoft Excel
Developed an interactive Adidas Sales & Performance Dashboard using Microsoft Excel to analyze sales data and evaluate overall business performance. The project involved data cleaning, transformation, and preparation to ensure data accuracy and consistency. Created calculated columns, KPIs, PivotTables, and interactive charts to analyze sales, revenue, products, retailers, regions, and sales trends. Designed a user-friendly dashboard that provides a clear visual overview of key business metrics and helps identify important patterns and performance trends for better data-driven decision-making.
